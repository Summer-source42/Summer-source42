## 🧪 Projects & Labs
 
### 🌐 Cisco Enterprise Network Design & Implementation
*Cisco Packet Tracer · CCNA · VLANs · OSPF · RIPv2 · DHCP · SSH · Port Security*
 
Designed and implemented three progressively complex enterprise networks from scratch a small branch office (SOHO), a multi-floor hotel network, and a large dual campus university network. Each project covers the full cycle: requirements analysis, topology design, manual subnetting, device configuration, and end-to-end verification.
 
The campus network is the most complex three routers, ten switches, two layer 3 multilayer switches, eight VLANs on the main campus, RIPv2 across all routers, and a simulated external cloud server reached via static routing.
 
🔗 [Repository Link](https://github.com/Summer-source42/Enterprise-Network-Project)
 
---
 
### 🔧 Azure Honeypot & Attack Map
*Azure · Microsoft Sentinel · Log Analytics · KQL*
 
Deployed a cloud honeypot on Azure and used Microsoft Sentinel to ingest, analyze, and visualize real-world brute-force login attempts from across the internet. Built custom KQL queries and an interactive attack map showing attack origins enriched with GeoIP data.
 
This was my first proper hands-on SIEM project working with real attack telemetry rather than synthetic lab data made a big difference in understanding what detection actually looks like.
 
🔗 [Repository Link](https://github.com/Summer-source42/azure-honeypot-attackmap)
 
---
 
### 🏢 Active Directory Home Lab
*Windows Server · Active Directory · GPO · Splunk · VirtualBox*
 
Built a multi-VM lab simulating an enterprise Active Directory environment domain services, Group Policy, DHCP, NAT, and automated user provisioning via PowerShell. Integrated Splunk for log collection and analysis to practice detection on a realistic environment.
 
🔗 [Repository Link](https://github.com/Summer-source42/active-directory-lab)
 
---
 
### 🛡️ File Integrity Monitor (FIM)
*PowerShell · SHA-512 · Windows*
 
Built a PowerShell-based file integrity monitoring tool that compares live file hashes against a stored baseline using SHA-512. Detects unauthorized file creations, modifications, and deletions in real time a practical introduction to basic host-based detection.
 
🔗 [Repository Link](https://github.com/Summer-source42/file-integrity-monitor)
